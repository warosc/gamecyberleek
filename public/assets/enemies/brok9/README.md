# BRÓK-9 — Comandante de la Brecha

Original Cyberleek antagonist, generated for this project using the owner's Cyberleek hero
as the style reference. Final PNG is a true RGBA cutout; the checkerboard concept is not shipped.

Visual direction: organic broccoli crown, stern magenta visor, graphite/violet military armor,
cyan seams, twin bio-plasma cannons, and a magenta chest reactor. The production renderer keeps
the character upright like the hero, with whole-body breathing, marching sway, recoil, an animated
ground ring and aligned reactor/cannon light overlays. This is a single painted sprite, not a
separated limb rig. Reduced motion disables bob, sway and ground rotation.

The encounter retains its existing hitbox, health, speed, projectile budgets and attack timings.
Phase names: Contención (violet), Sobrecarga (amber), Ruptura (red). Health notifications are emitted
by the shared enemy damage method, including Nova and splash damage.
